# Security Policy

## Reporting a security issue

Please do not publish sensitive credentials, API keys, tokens, passwords, private keys, or other confidential information in issues or pull requests.

For security concerns involving this portfolio repository, use GitHub's private vulnerability reporting features when available.

## Portfolio security principles

- No real credentials belong in source files.
- Secrets should be stored through appropriate secret-management mechanisms.
- Example configuration should use placeholders only.
- AI-assisted code should be reviewed and tested before being treated as reliable.
- Project claims should be supported by repository evidence.
