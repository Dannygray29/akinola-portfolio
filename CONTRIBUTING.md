# Contributing

This repository is primarily a personal professional portfolio.

Suggestions that improve clarity, accessibility, documentation, security, or factual accuracy are welcome.

## Guidelines

- Keep changes professional and evidence-based.
- Do not add personal credentials, secrets, or private information.
- Do not add invented experience, qualifications, clients, or achievements.
- Preserve attribution for third-party and fork-derived projects.
- Clearly distinguish AI-assisted work from independent technical expertise.
